## 🎯 Our Core Principles

Everything we build is guided by three foundational principles:

### 1️⃣ Simple Over Complex
We avoid unnecessary bloat and dependencies. We build clean, lightweight utilities that focus on doing one thing exceptionally well.

### 2️⃣ Clean UI Over Overdesign  
Aesthetics should serve usability. Our designs focus on high contrast, readable typography, and structured spatial layouts without superficial clutter.

### 3️⃣ Build → Learn → Improve
We approach software as a continuous cycle of creation, validation, and iteration. We ship code fast, learn from real-world usage, and refactor relentlessly.

## 🛠️ Featured Utilities

### [MenuForge](https://crystal-studio-labs.github.io/pages/projects.html#menuforge)
A professional-grade Linux terminal UI utility that bridges manually installed binaries, scripts, and games directly into desktop environments with automated performance tuning.

**Stack:** Shell • **Latest:** v1.2.0 • **Stars:** ⭐⭐⭐⭐⭐

---

### [CrystalSystem.js](https://crystal-studio-labs.github.io/pages/projects.html#crystalsystem)
A zero-dependency real-time system resource monitor for Node.js. Displays CPU, RAM, Battery, Disk, and Network telemetry in your terminal with a companion HTTP API, CLI, and alerting engine.

**Stack:** JavaScript/TypeScript • **Latest:** v1.0.0 • **Dependencies:** 0

---

### [InkMD](https://crystal-studio-labs.github.io/pages/projects.html#inkmd)
A browser-based Markdown editor with a local-first philosophy. Renders split-pane live-previews with GitHub Flavored Markdown support, syntax highlighting, and offline-ready exports.

**Stack:** TypeScript/React • **Philosophy:** No tracking, fully client-side

---

### [Orion-Net & Orion-Deck](https://crystal-studio-labs.github.io/pages/projects.html#orion)
A lightweight, decentralized, and ephemeral messaging suite. Orion-Net acts as the backend WebSocket room server with Proof-of-Work protection, while Orion-Deck provides an interactive, terminal-native client UI.

**Stack:** Python/Rich • **Latest:** v1.0.2 • **Security:** Ephemeral & E2E concepts

---

### [crystal-auth](https://crystal-studio-labs.github.io/pages/projects.html#crystalauth)
An early-stage authentication and security helper library designed to provide lightweight session routines and identity validation helpers for web interfaces and server architectures.

**Stack:** JavaScript/TypeScript • **Status:** Early Access
